# ARC Rebrand + 2026 Championship Content Updates — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Update site copy for the RoboMaster North America → ARC rebrand, add a "What Is ARC" section to `/about`, reorder robots to Infantry → Sentry → Hero, and add the 2026 ARC Championship event with its top-8 result.

**Architecture:** Nearly all changes are string edits to `src/content.json`, which is the source of truth for every piece of text on this site (see `CLAUDE.md`). Four files of supporting code render the new data: a glob fix in `configs/loadImages.js`, a new section in `About.jsx`, three edits in `Event.jsx`, and matching CSS. Tests are content-driven — they read `content.json` rather than hardcoding strings — so they validate the real data and keep validating it as content changes.

**Tech Stack:** React 18, Vite 6, Vitest + jsdom + @testing-library/react, framer-motion (untouched here).

**Spec:** `docs/superpowers/specs/2026-08-08-arc-content-updates-design.md`

## Global Constraints

- **All npm commands run from `react-ursaworks/`.** Nothing works from the repo root.
- **Run tests with `npx vitest --run`.** Plain `npm test` starts watch mode and will hang an agent.
- **Lint with `npm run lint`** before every commit. It must pass clean.
- **Never edit `src/assets/` or `public/assets/`** — both are generated by `syncAssets.js`. Images are edited in `content/assets/` only.
- **`src/content.json` must stay valid JSON.** It is imported directly; a syntax error breaks the whole app.
- **Copy is verbatim.** Every string in this plan is final, reviewed, and sourced. Do not reword, "improve", fix perceived typos, or normalize punctuation. The `·` separators and `—` em dashes are intentional and match existing entries.
- **Historical event names stay as they are.** `RMNA 2023/2024/2025` and `Midwest 2023/2024/2025` are correct — those events happened under the old name. Only `competitions[]` gets rebranded.
- **Do not change the `robomasterna.com` href.** It resolves to the ARC site. Only the visible label changes.
- **Do not touch `Contact.jsx`.** Its "ARC Robotics Competition" wording is correct.
- Existing tests `RobotsTeaser.test.jsx` and `EventTeaser.test.jsx` read from `content.json` and must keep passing without edits. If one breaks, that is a real signal — stop and report, do not adjust the test to fit.

Create `src/__tests__/contentImages.test.js`:

```js
import fs from 'node:fs';
import content from '../content.json';

// Parse the extension list out of the real glob so this test cannot drift from
// it. An image whose extension is missing there resolves to null and renders as
// a broken image, with only a console.error to show for it.
const loaderSource = fs.readFileSync(
    new URL('../configs/loadImages.js', import.meta.url),
    'utf8'
);
const supported = loaderSource.match(/\*\.\{([^}]+)\}/)[1].split(',');

const referencedImages = [
    content.aboutImage,
    ...content.robots.map((robot) => robot.image),
    ...content.events.map((event) => event.image),
    ...content.team.map((member) => member.image),
];

test.each(referencedImages)('%s has an extension loadImages can resolve', (filename) => {
    expect(supported).toContain(filename.split('.').pop().toLowerCase());
});
```
